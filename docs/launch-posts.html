Title: Wormsign: check npm/PyPI packages and suspicious hooks, editor tasks and autostart entries

Link submission URL: https://github.com/mansoor-mamnoon/wormsign. Use the following as the description or first comment if the community permits it.

Wormsign is an open-source Go CLI for checking known-malicious npm/PyPI package versions alongside local persistence indicators.

Upgrading a package doesn't remove a hook or service it already installed. Wormsign checks supported package files, coding-agent configurations, VS Code folder-open tasks and common autostart locations together.

Try the harmless fixture:

    brew install mansoor-mamnoon/tap/wormsign
    wormsign --demo --offline

One binary, no account or API key. It reports findings without running package scripts or removing anything.

Online scans send package ecosystem, name and version to OSV, potentially including private names. Offline mode skips that lookup: it cannot check package versions. Local pattern matches need inspection, and a clean report isn't proof that a machine is safe.

Code, demo and limitations: https://github.com/mansoor-mamnoon/wormsign

r/SideProject

Title: A CLI for checking what a malicious package might leave behind

Wormsign combines known-malicious npm/PyPI version checks with inspection of supported agent hooks, editor tasks and autostart entries.

The problem it addresses: replacing a dependency is not the same as checking for persistence it may have installed. The output gives you paths to investigate rather than trying to clean your machine automatically.

There's a harmless demo, so you don't need an infected project to see the report:

    brew install mansoor-mamnoon/tap/wormsign
    wormsign --demo --offline

It's a Go binary with no third-party Go dependencies. For a project-only scan, use `wormsign --project .`.

This is triage, not an antivirus or a guarantee of safety. Online package checks send names and versions to OSV; offline mode only checks local indicators. Autostart coverage focuses on macOS and Linux.

Repo and demo: https://github.com/mansoor-mamnoon/wormsign
